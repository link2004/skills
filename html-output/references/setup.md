# 初回セットアップ手順

このスキルを別Macに配布した時、または初めて使う時の手順。

## 0. 前提

- AWSアカウントへの管理者権限（IAMユーザー作成・S3バケット作成ができること）
- AWS CLI v2 インストール済み
- 既存のAdmin profile（SSO or IAM）でCLI認証済み（以下 `<ADMIN_PROFILE>` と表記）

## 1. config.json を用意

```bash
cd ~/.claude/skills/html-output
cp config.example.json config.json
$EDITOR config.json
```

埋めるべき値:

| key | 例 | 説明 |
|---|---|---|
| `bucket` | `john-html` | S3バケット名（**グローバル一意・後から変更不可**） |
| `region` | `ap-northeast-1` | バケットを作るリージョン |
| `aws_profile` | `john-html` | このスキル用のprofile名（既存と被らないように） |
| `iam_user` | `john-html-uploader` | このスキル専用のIAMユーザー名 |
| `aws_account` | `123456789012` | 12桁のAWSアカウントID |
| `default_expires_seconds` | `604800` | presigned URLのデフォルト有効秒数（最大7日=604800） |
| `footer_text` | `Generated by Claude Code` | HTML下部の表記 |

## 2. S3バケット作成

config.jsonの値を環境変数に出してから:

```bash
BUCKET=$(python3 -c "import json; print(json.load(open('config.json'))['bucket'])")
REGION=$(python3 -c "import json; print(json.load(open('config.json'))['region'])")

aws s3api create-bucket \
  --bucket "$BUCKET" \
  --region "$REGION" \
  --create-bucket-configuration "LocationConstraint=$REGION" \
  --profile <ADMIN_PROFILE>
```

`us-east-1` の場合は `--create-bucket-configuration` を省略する。

## 3. IAMユーザー＋最小権限ポリシー

```bash
IAM_USER=$(python3 -c "import json; print(json.load(open('config.json'))['iam_user'])")

aws iam create-user --user-name "$IAM_USER" --profile <ADMIN_PROFILE>

cat > /tmp/policy.json <<EOF
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "ListBucket",
      "Effect": "Allow",
      "Action": ["s3:ListBucket", "s3:GetBucketLocation"],
      "Resource": "arn:aws:s3:::${BUCKET}"
    },
    {
      "Sid": "ObjectRW",
      "Effect": "Allow",
      "Action": ["s3:PutObject", "s3:GetObject", "s3:DeleteObject"],
      "Resource": "arn:aws:s3:::${BUCKET}/*"
    }
  ]
}
EOF

aws iam put-user-policy \
  --user-name "$IAM_USER" \
  --policy-name HtmlOutputBucketOnly \
  --policy-document file:///tmp/policy.json \
  --profile <ADMIN_PROFILE>

rm /tmp/policy.json
```

## 4. Access key発行 → ~/.aws/credentials に書き込み

**重要**: シークレットを画面に出さないため、pipe経由でcredentialsファイルに直接書き込む。

```bash
PROFILE=$(python3 -c "import json; print(json.load(open('config.json'))['aws_profile'])")
REGION=$(python3 -c "import json; print(json.load(open('config.json'))['region'])")

aws iam create-access-key --user-name "$IAM_USER" --profile <ADMIN_PROFILE> \
  --query 'AccessKey.[AccessKeyId,SecretAccessKey]' --output text \
  | (read AKID SK; printf '\n[%s]\naws_access_key_id = %s\naws_secret_access_key = %s\nregion = %s\n' \
      "$PROFILE" "$AKID" "$SK" "$REGION" >> ~/.aws/credentials \
      && echo "saved to ~/.aws/credentials [$PROFILE]")
```

## 5. 動作確認

IAMの propagation で数秒かかるので待ってから:

```bash
sleep 8
AWS_PROFILE="$PROFILE" aws s3 ls "s3://$BUCKET/" && echo "auth OK"
```

## 6. （任意）alias追加

```bash
cat >> ~/.zshrc <<EOF

# html-output skill bucket
alias htmlup='AWS_PROFILE=$PROFILE aws s3 cp'
alias htmlls='AWS_PROFILE=$PROFILE aws s3 ls s3://$BUCKET/'
alias htmlrm='AWS_PROFILE=$PROFILE aws s3 rm'
EOF
```

## トラブルシューティング

| エラー | 対処 |
|---|---|
| `BucketAlreadyExists` | `bucket` 名がグローバルに被っている。別名にする |
| `InvalidAccessKeyId`（直後） | IAM eventual consistency。10秒待って再試行 |
| `Token has expired` | `<ADMIN_PROFILE>` がSSOなら `aws sso login --profile <ADMIN_PROFILE>` |
| `An error occurred (AccessDenied)` | 既存のbucketに別人がpolicyを当てている可能性。bucket名を変える |
